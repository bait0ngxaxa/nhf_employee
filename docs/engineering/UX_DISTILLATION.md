# การปรับภาษาและการแสดงสิทธิ์ใน NHFapp

งานนี้ครอบคลุมหน้าเว็บสำหรับพนักงานและผู้ปฏิบัติงาน หน้า LINE และหน้าจัดการสิทธิ์ [เอกสารสถานะสิทธิ์ปัจจุบัน](../architecture/authorization-current-state.md) บันทึกกฎหลัง Phase 12H-I และเงื่อนไขผู้รับแจ้งเตือน Phase 13A.2 รวมถึงบริการ IT บน LINE และการแก้ไขคำร้องพนักงานใหม่ การออกแบบหน้าผู้ดูแลอ้างอิง Phase 12G-A โดยใช้กฎจาก implementation ปัจจุบัน บทบาทระบบ ADMIN เปิดหน้าจัดการสิทธิ์ตามเงื่อนไขเดิม สิทธิ์ทำงานมาจากนโยบายของบริการและสิทธิ์ที่กำหนดเพิ่มเติม

## ข้อจำกัดของข้อมูลที่หน้าจอได้รับ

- หน้า LINE สำหรับ Leave และ Routine เห็น feature flag ที่ตรวจฝั่งเซิร์ฟเวอร์ก่อนเปิดหน้า ส่วน modules.*.enabled จาก LIFF Home รวมสถานะบริการกับผลการเข้าถึงของบัญชี เมื่อผลเปลี่ยนระหว่างใช้งาน ข้อความระบุว่าบัญชีเปิดบริการไม่ได้ตามผลที่ได้รับ การระบุสาเหตุละเอียดกว่านี้ต้องแยกข้อมูลใน API contract
- หน้าเว็บ Routine ที่ถูกปิดยังพากลับหน้าหลักตาม route guard เดิม หน้าเว็บ Leave มีข้อความว่าบริการยังไม่เปิดอยู่แล้ว
- ผลการค้นหารหัส capability, scope และ role ที่เหลือใน JSX เป็นค่าในโค้ด รหัสแผนกในงานนำเข้า หรือข้อมูลในเครื่องมือจัดการสิทธิ์ Request ID ในหน้าจัดการสิทธิ์ยังใช้ประสานการตรวจปัญหา
- การทดสอบครอบคลุมการแสดงผลตาม fixture และการบังคับใช้ฝั่ง API การใช้บัญชีจริงบน LINE และการยอมรับจากเจ้าของกระบวนงานต้องใช้หลักฐานการตรวจแยกต่างหาก
